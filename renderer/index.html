搜索与安全

逻辑用户编号（LUID）

登录后下发一个只有服务端知道映射的编号，前端带着它即可鉴权；命中缓存不查库，登出即失效。可按 LUID / 用户 ID 做数据归属。

短信 / 邮箱验证码（只做对接）

我们不做服务器：这里配的是你自己的网关，生成后 POST /captcha/send 会把「接收方 / 验证码 / 场景」POST 过去。provider 选 none 时只打 dry-run 日志。

防护（WAF / 防火墙）

进程内的第一道闸：SQL 注入、XSS、路径穿越、CC 限流、并发上限、CORS、安全响应头。上线建议前面再挂一层 Nginx / ONRouter。

集群与分流

多库多集群：主库写、从库读，按权重分流；写前抢 Redis 租约，抢不到就拒写（防脑裂）。

网关与微服务

网关只做鉴权透传、限流和转发；微服务按画布上的服务节点（没画就按模块分组）拆成多个可独立部署的工程。
