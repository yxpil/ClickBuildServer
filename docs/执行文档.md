## 1. 目标与边界

### 1.1 目标
把原来的“勾业务模块 → 整台服务器一次生成”改成 **接口为中心** 的制造台：

- 一个接口 = 一条业务线；接口里可以挂 **多张表、多个库、多个连接**；
- 每条路由 = 一段 **可自定义的 SQL 脚本**，支持多语句、条件、循环、事务；
- SQL 里能直接调扩展函数（哈希 / 国密 / 截取 / 编码 / 自定义），也能在 SQL 与 Redis、对象存储之间三向联动；
- 界面是 **黑白简约的 Excel / Office 风**（不刻意复古），分类 sheet 页、全局搜索、SVG 图标、`logo.png` 做应用图标；
- 生成物自带运行时（`runtime\node\node.exe` 复制进仓库），不依赖系统解释器；
- 与本机三台测试服务联调（MariaDB 13306 / Redis 16379 / RustFS 19000）。

### 1.2 明确不做 / 暂缓
- 不做“一个接口只能一张表”的教条：后续每轮都允许一接口多表多库。
- 不刻意复古：不做纸张纹理、打字机字体、棕黄色调。
- 不把 Electron 原生菜单留着：已移除；系统标题栏暂时保留（自绘无边框还没做）。
- 跨实例分布式事务：只做单池事务 + 补偿 + 日志，不做 XA / 两阶段。

### 2.1 关键设计决定

| 决定 | 原因 |
| --- | --- |
| 脚本按 **行式语法**，不引入完整 JS 引擎 | 生成服务只依赖 `mysql2/ioredis/minio`，不额外背一个解释器；导出 JS/Java/Go 也容易 |
| 所有用户值一律 `?` 参数化 | 注入面最小；不用字符串拼值 |
| 表引用不写死表名，用 `{{t:key}}` | 复制接口、换库、多表联查时不用改脚本 |
| SQL 函数在“执行前”由解释器算成参数 | 避免 MySQL/MariaDB 不认 `SM4_ENC`、`HASH` 这类函数名 |
| 写路由默认 `guard.tx=true` | 默认安全；要关就关 |
| 日志分级 + 可换库 | 用户要求“按等级存到指定数据库”，日志连接是独立配置 |
| `.yxpn` = ZIP + manifest | 压缩、可校验、带导出代码与文档；纯 Node 实现，不依赖系统 zip |

## 4. 脚本解释器（`app/iface/script.js`）

### 4.1 语句

| 语法 | 说明 |
| --- | --- |
| `LET $x = QUERY SQL;` | 查询，结果 `{ rows, sql, params }` |
| `LET $x = EXEC SQL;` | 写入，返回 `insertId/affectedRows` |
| `LET $x = 表达式;` | 局部变量 |
| `IF cond` / `ELSEIF` / `ELSE` / `END` | 条件 |
| `FOREACH $row IN $list` / `END` | 循环 |
| `TX BEGIN|COMMIT|ROLLBACK` | 手动事务（默认写路由已自动开） |
| `LET $x = HTTP GET|POST|PUT|DELETE 'url' {json};` | 服务间 HTTP（15s 超时） |
| `PUBLISH 'channel' expr;` | Redis 发布 |
| `LET $x = TOKEN NEW|GET expr;` / `TOKEN DEL expr;` | onlyId + token 会话 |
| `LOG TRACE|DEBUG|INFO|WARN|ERROR|FATAL expr;` | 分级日志 |
| `RETURN [status] {json};` | 结束并返回 |

### 4.2 表达式
`$var`、`$var.rows[0].field`、`{{body.x}}`、字符串/数字/布尔、`{ ... }` 对象、`[ ... ]` 数组、函数调用（大小写不敏感）、`== != > < >= <= && || !`、括号。

SQL 里可以直接写脚本变量：`$i.product_id`、`$oid.rows.0.id` 会在执行前解析成参数（解析不到就原样保留给数据库报错）；也可以显式写 `{{vars.i.product_id}}`、`{{last.insertId}}`。LET 的结果同时写入 `last`，所以上一句是 INSERT 时 `{{last.insertId}}` 就是新主键。

### 4.3 SQL 函数前置展开
执行 SQL 前，解释器把 SQL 文本里的 `HASH(...)`、`MD5(...)`、`SHA256(...)`、`SM3(...)`、`SM4_ENC/DEC(...)`、`MASK(...)`、`URL_ENC/DEC(...)`、`RAND_INT(...)` 以及自定义函数算成本地值，再换成 `?`。白名单 `SQL_EXPAND` 只放这些，避免把 SQL 原生的 `LEFT/RIGHT/IN` 误判。

### 4.4 导出
`scriptToJs` 把同一份 AST 转成 JS（生成服务的 `src/script.js` 与 `export/js/*.js` 共用），`export/java`、`export/go` 输出骨架 + 原 SQL 注释 + 请求示例。

## 6. 生成的服务（`app/iface/template/server.js`）

启动顺序：

1. 读取 `interfaces.json`（工程 + 连接 + 日志 + token + services）；
2. 建 MySQL 池：`CONNS.mysql` → `pools`，`poolFor(key)`；
3. 逐连接执行 `sql/*.sql`（独立 `multipleStatements` 连接，幂等 DDL）；
4. `RESET_DB=1` 时先 DROP 本工程库再建；
5. 注册路由：`auth` → 限流 → 时间窗 → 熔断 → 事务 → 脚本；
6. 启动 HTTP（默认 18100）。

内置端点：

| 端点 | 用途 |
| --- | --- |
| `GET /_health` | mysql/redis/s3 三件套 |
| `GET /_meta` / `/_routes` | 连接、日志、token、路由清单 |
| `GET /_docs` / `/docs` | OpenAPI 3.0.3 / HTML 文档 |
| `GET /_logs?tail=N` / `/_logs/stream` | 日志快照 / SSE |
| `/sql/*` | 建表脚本静态访问 |
| `/` | 生成服务自带的控制台（试路由、看健康） |

护栏：

- **事务**：写路由从池里取连接 `beginTransaction`，异常 `rollback` 并写 FATAL；提交失败再补偿回滚，失败则靠日志追。
- **限流**：Redis `INCR` + 过期窗口，Redis 不可用退内存计数。
- **时间窗**：支持跨零点（如 22:00–06:00）。
- **熔断**：连续失败超过阈值 → 503 + `retry-after`，冷却后半开。
- **日志**：控制台彩色、内存环形 500、SSE 广播、按 `log.level` 过滤后落 `sys_log`（独立连接可换库），字段含 iface/route/method/path/status/ms/ip/trace_id/message/meta。
- **token**：`icb:token:<token>` ↔ `icb:only:<onlyId>` 双向，支持 `Authorization: Bearer` 或 cookie；`/me` 用 `ctx.user`。
- **对象存储**：MinIO 自动建桶，presigned 上传，回填 `{{objectKey}}`。

## 9.4 Defender 信任目录（`app/iface/defender.js`）

- `defender.list()` 读 `Get-MpPreference` 的 ExclusionPath/Process。
- `defender.trust()` 把工程根、`runtime`、`runtime\node`、`generated`、`node_modules` 加入排除，并排除 `node.exe` / `electron.exe`。
- 需要管理员权限；失败会把 PowerShell 原始错误带回来，UI 直接显示，不假装成功。

## 9.5 微服务导出与守护包

- 入口：Ribbon `服务 → 微服务`，或接口行右键“导出此接口为微服务”。
- 勾选分类会带上整类接口，也可只勾单个接口；`codegen.generate` 用 `only` / `category` 过滤，产物仍是完整服务（含 OpenAPI、导出代码、控制台、文档）。
- 输出目录：`generated/iface/<你起的名字>`；改名后要同步改 `.env` 的 `PORT`、`MYSQL_DB`、`CACHE_PREFIX`，避免和主服务抢端口 / 串库 / 串缓存。
- 每个生成物自带 `daemon/watchdog.js`、`daemon/start.ps1`、`daemon/install-service.ps1`：崩溃按 1s→10s 退避重启，日志 `daemon/daemon.log`；`install-service.ps1` 用 `schtasks` 建登录自启任务。
- 实测：单接口微服务（`守护测试`）在 18190 正常健康检查与路由；杀掉子进程后 watchdog 3 秒内拉起，`/_health` 恢复。

## 13. 关键坑与修复记录

| 现象 | 原因 | 修复 |
| --- | --- | --- |
| `TOKEN NEW {...}` 报“表达式多出了内容” | `LET` 分支先吃掉整行，未识别 `TOKEN/HTTP` | 在 `LET` 分支内先判 `TOKEN` / `HTTP` |
| `scriptToJs` 读 `st.sql.replace` 崩 | HTTP/TOKEN 语句没有 `sql` 字段 | 按 `from` 分支生成 + 导出模板补 `H/T/TX/P/TD/L` |
| 复制接口后校验 3 处错 | 路由 method+path 重复 | `cloneIface` 对路径做 `-2` 后缀避让 |
| 注册接口 SQL 报 `ER_FUNC_INEXISTENT_NAME_COLLISION` | `HASH()` 直接下发 MySQL | 执行前 `expandSqlFunctions()` 本地算完换 `?` |
| RETURN 里 `{{body.x}}` 崩 | scope 没带 ctx | scope 改为 `{...env, vars, last}` |
| 界面白屏 `Identifier 'icb' already declared` | 全局名与 preload 冲突 | 改用 `const api = window.icb` |
| 命令行生成崩 `app.getPath` | 纯 Node 无 Electron | `store.js` 安全 require + APPDATA 兜底 |
| `mariadb-install-db` exit 7 | 不接受 `--character-set-server` | 去掉这两个参数 |
| 原生菜单残留在窗口顶 | 默认模板 | `Menu.setApplicationMenu(null)` |
| 商城服务 `RESET_DB=1` 把 `clickbuild` 库也 DROP 了 | 连接配置的库为空，回落到平台默认库 | 新增 `dbOf()`：空库/平台默认库跟随 `MYSQL_DB`，显式库名才按配置 |
| 两个工程共用一个 Redis，缓存互串 | 缓存键只按表名 | 每个工程 `CACHE_NS = icb:cache:<工程名>`，写入/失效/重置都只碰自己的前缀 |
| 订单明细插入报 `Unknown column '$i.product_id'` | SQL 不会读脚本变量 | `renderSqlText()` 先把 `$var.path` 解析成参数；配合 `LET $oid = QUERY SELECT LAST_INSERT_ID()` + `{{vars.oid.rows.0.id}}` |
| 启用插件后生成的文档少一行/多一行，E2E 数量对不上 | 插件会改写 docs 和脚本 | 测试统一在应用插件后的工程上断言；插件失败只记 warnings |
| Ribbon 右侧状态把“生成的服务 18100”挤成竖排 | 新增两组后 flex 收缩 | 状态区改为端口提示 + 分组 `flex:0 0 auto`、标签 `nowrap` |
